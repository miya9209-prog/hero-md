# Streamlit 배포

공식 참고:

https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/deploy

## 순서

1. GitHub에 repo 업로드
2. Streamlit Community Cloud 로그인
3. Create app
4. repo 선택
5. main branch
6. `app.py`
7. Advanced settings에서 Secrets 입력
8. Deploy

Secrets는 코드 저장소에 넣지 않습니다.
