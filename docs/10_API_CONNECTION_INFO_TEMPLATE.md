# API 연결정보 입력표

민감정보는 이 문서에 실제 값으로 적지 말고 어디에서 발급받았는지만 기록하세요.

| 구분 | 필요한 값 | 상태 |
|---|---|---|
| Supabase | DATABASE_URL | 기존 연결 유지 |
| Cafe24 | Mall ID | 기존 |
| Cafe24 | Client ID/Secret | 기존 |
| Cafe24 | Scope | `mall.read_product mall.read_order mall.read_analytics` |
| Sellmate | Base URL | 발급 필요/확인 |
| Sellmate | API Token | 발급 필요/확인 |
| Sellmate | Inventory Endpoint | 발급 문서 확인 |
| Sellmate | Response field map | 발급 문서 확인 |
| SERA | 최신 보고서 엑셀 | 운영 업로드 |
| SERA | 직접 다운로드 URL(선택) | 있으면 자동화 |
