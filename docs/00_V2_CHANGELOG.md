# MISHARP HERO ITEM OS v2 변경사항

## 핵심 원칙
- 실제 재고의 기준 데이터는 **셀메이트 API**입니다.
- **Cafe24 Admin 재고수량은 HERO 판단과 현재고 계산에 사용하지 않습니다.**
- 상품 행동/판매 통계는 **Cafe24 Analytics**를 1차 기준으로 사용합니다.
- **SERA**는 조회·주문·판매·OpV·ESpV·클릭가치 등 보완 신호와 교차검증 데이터로 사용합니다.

## UI
- 프로그램명: **MISHARP HERO ITEM OS**
- 좌측 사이드바 제거
- 상단 메뉴: 히로 레이더 / 상품 마스터 / 상품 스케줄 / 48H 판정 / 월간 HERO / MD 실행 / 데이터·설정
- 향후 SELLER OS 안에 모듈로 편입하기 쉬운 구조로 변경

## 자동 데이터 수집
- Cafe24 상품 마스터: 전체/증분 동기화
- Cafe24 Analytics: 상품조회, 장바구니, 판매건수, 판매수량, 매출
- Sellmate: 실제 현재고/가용재고
- SERA: 엑셀 업로드 + 선택적 원격 보고서 URL 자동수집
- 30분 주기/일일 GitHub Actions 작업 포함

## HERO 판단
- CVR, RPV, 장바구니율, 판매수량, 매출, 조회수, SERA 보조신호를 조합
- HERO / 숨은 HERO / 전환문제 / 구매 직전 이탈 / 재검토 자동진단
- 실제 재고는 점수 자체보다 실행경고(재발주/품절위험)에 사용

## 기존 데이터 보존
- 기존 Supabase DB를 그대로 사용합니다.
- 기존 products, OAuth token 등 레거시 테이블을 삭제하지 않습니다.
- 신규 통계/재고/HERO v2 테이블만 추가 생성합니다.
