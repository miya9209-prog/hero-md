# HERO Score v2.2

## 출시 후 48H 점수

확정 가중치:
- 구매전환율(CVR) 30%
- 조회당 매출(RPV) 25%
- 판매수량 20%
- 매출액 15%
- 조회수 10%

합계 100%입니다.

장바구니율과 SERA 클릭가치/OpV/ESpV는 **HERO Score에 직접 가중하지 않고 진단·교차검증 보조지표**로 사용합니다.

히스토리가 5개 이상 쌓이면 같은 미샵 상품 히스토리 안의 백분위 점수로 평가하고, 히스토리가 부족한 초기에는 절대 기준을 사용합니다.

재고는 HERO 수요 점수 자체에 직접 가중하지 않고 **실행판단**에 사용합니다.
- HERO + 재고 0 → 결품/재발주 경고
- HERO + 저재고 → 재고주의

## 등급
- 85~100: 🔥 HERO
- 70~84: 💎 HERO 유력
- 55~69: 관찰
- 0~54: 재검토

## 자동진단
- 조회 높음 + CVR 높음 → HERO
- 조회 낮음 + CVR 높음 → 숨은 HERO(노출 확대)
- 조회 높음 + CVR 낮음 + 장바구니 높음 → 구매 직전 이탈
- 조회 높음 + CVR 낮음 + 장바구니 낮음 → 상세/가격/핏 전환문제
- 모두 낮음 → 우선순위 재검토
