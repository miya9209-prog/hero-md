# HERO Score v2

## 출시 후 점수

초기 가중치:
- CVR 25%
- RPV 20%
- 장바구니율 15%
- 판매수량 15%
- 매출 10%
- 조회수 10%
- SERA 클릭가치 5%

히스토리가 쌓이면 절대 기준 대신 미샵 상품 히스토리의 백분위 점수로 자동 전환합니다.

재고는 HERO 수요 점수 자체에 직접 가중하지 않고 **실행판단**에 사용합니다.
- HERO + 재고 0 → 결품/재발주 경고
- HERO + 저재고 → 재고주의

## 자동진단

- 조회 높음 + CVR 높음 → HERO
- 조회 낮음 + CVR 높음 → 숨은 HERO(노출 확대)
- 조회 높음 + CVR 낮음 + 장바구니 높음 → 구매 직전 이탈
- 조회 높음 + CVR 낮음 + 장바구니 낮음 → 상세/가격/핏 전환문제
- 모두 낮음 → 우선순위 재검토
