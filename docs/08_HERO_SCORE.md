# 히로 점수(HERO Score)

## 1단계 — 출시 전

설명 가능한 점수 모델입니다.

MD가 왜 높은 점수가 나왔는지 이해할 수 있게 설계합니다.

## 2단계 — 48H

히스토리가 5건 미만이면 임시 절대기준을 사용합니다.

5건 이상부터는 백분위 기반으로 전환합니다.

## 3단계 — 데이터 축적 후

추가 예정:

- 카테고리 HERO 성공률
- 공급처 HERO 성공률
- 가격대 HERO 성공률
- 월/시즌 성공률
- HERO DNA 유사도
- 초도량 대비 판매속도
- 재주문 리드타임
- 반품률
- 광고 투입 후 증분효과
