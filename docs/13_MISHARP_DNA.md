# 미샵 DNA

## 목적
최근 3년 실제 판매성과에서 시기별로 잘 팔린 상품의 공통점을 찾아 다음 신상품 기획에 활용합니다.

## 메뉴 위치
상품 탐색 / 상품 판정 및 후속업무 관리 / **미샵 DNA** / 상품DB / 데이터·설정

## 분석 범위
- 최근 3개월 / 6개월 / 12개월 / 24개월 / 36개월
- 3년 이전 상품은 전체 상품DB에는 보존하지만 DNA 분석에서는 제외

## 성공상품 기준
- 매출
- 판매수량
- 구매전환율(CVR)
- 조회당 매출(RPV)

## 자동 추출
- 강한 카테고리
- 반응 좋은 가격대
- 상품명 반복 핵심어
- 상위상품 평균/중앙 구매전환율(CVR), 조회당 매출(RPV), 조회수
- 다음 신상 기획 가이드

## 해석 원칙
미샵 DNA는 과거 베스트를 그대로 복제하라는 기능이 아닙니다. 데이터에서 반복되는 고객반응 신호를 찾아 MD가 다음 상품을 고를 때 무엇을 먼저 확인할지 제안하는 기능입니다. 현재 트렌드, 고객 VOC, 원가와 공급조건을 함께 판단합니다.
