# v3.1 TEAM + 미샵 DNA

## 최종 메뉴 순서
1. 상품 탐색
2. 상품 판정 및 후속업무 관리
3. 미샵 DNA
4. 상품DB
5. 데이터·설정

## 이번 최종 변경
- 관리자 비밀번호 방식 완전 제거
- 미샵 DNA를 3번째 핵심 메뉴로 추가
- 최근 3년 월별 Cafe24 Analytics 학습데이터만 DNA 분석에 사용
- 최근 3/6/12/24/36개월 선택 분석
- 매출/판매수량/구매전환율(CVR)/조회당 매출(RPV) 기준 전환 가능
- 상위상품 공통 카테고리, 가격대, 상품명 반복 키워드 추출
- 상위상품 초기 기대선과 다음 신상 기획 가이드 제안
- 3년 이전 상품은 상품DB에는 보존하지만 DNA 분석에서 제외

## DNA의 역할
과거 베스트를 복제하는 기능이 아니라, 현재 MD가 다음 신상을 선정할 때 무엇을 먼저 확인해야 하는지 데이터로 질문과 우선순위를 제안하는 기능입니다.
